# TypeScript Assignment 1

This repository contains a small set of TypeScript exercises focused on core language features such as arrays, strings, unions, generics, interfaces, classes, and set-based logic.

## Overview

The main implementation lives in [solutions.ts](solutions.ts) and includes:

1. Filtering even numbers from an array.
2. Reversing a string.
3. Detecting whether a value is a string or a number.
4. Reading a property from a generic object safely.
5. Extending a book type with read-status information.
6. Modeling a person/student class hierarchy.
7. Finding the unique intersection between two number arrays.

Each solution is written in TypeScript to demonstrate basic typing patterns and reusable function design.
